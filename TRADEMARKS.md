`LICENSE`). That license covers the code only. It does not cover the
project's name or identity.

## What is a trademark

- The name "Mundaréu".
- The Mundaréu logo.
- The game's visual identity.

## What the code license does not grant

The MIT license gives no right to use the name, the logo, or the visual
identity. In particular, you may not use them on:

- a fork of this project;
- a build of the game you distribute;
- an app-store listing.

A fork must ship under its own name, logo, and identity. The game's assets
are a separate matter: they are all rights reserved (see `assets/LICENSE`).

## What is fine

- Referring to the project by name to describe compatibility or origin, for
  example "a fork of Mundaréu".
- Contributing to this repository.
